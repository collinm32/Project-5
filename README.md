# CIVE 202 - Project 5 

## Project Overview
This repository contains the engineering deliverables, code, and project management documentation for Project 5 of CIVE 202 (Spring 2026) by team **ENVRN-01-18**. 

## Repository Contents

### 💻 Code & Data
* **`CIVE202_Spring2026_ENVRN-01-18_Project5_PythonCode.ipynb`**: The main Jupyter Notebook containing the Python codebase, calculations, and data analysis for the project.
* **`CIVE202_Spring2026_ENVRN-01-18_Project5_RRVWSP.csv`**: The dataset utilized by the Python script for analysis.
* **`CIVE202_Spring2026_ENVRN-01-18_Project5_AnnotatedCode.docx`**: A detailed document containing line-by-line annotations and explanations of the programmatic logic used in the Jupyter Notebook.

### 📋 Project Management & Documentation
* **`CIVE202_Spring2026_ENVRN-01-18_Project5_ScopeOfWork.docx`**: The formal Scope of Work (SOW) defining the project's objectives, boundaries, and required deliverables.
* **`CIVE202_Spring2026_ENVRN-01-18_Project5_FlowChart.pdf`**: A flowchart diagramming the process logic, algorithmic steps, and decision points for the project.
* **`CIVE202_Spring2026_ENVRN-01-18_Project5_GanttChart.xlsx`**: The project schedule, timeline, and task dependencies.
* **`CIVE202_Spring2026_ENVRN-01-18_Project5_EngineeringTimesheet.docx`**: Log of engineering hours spent by the team on various project tasks.

## Getting Started
To review the code and run the analysis locally:

1. Clone this repository to your local machine.
2. Ensure you have a Python environment set up with **Jupyter Notebook** (or JupyterLab/VS Code) installed. Standard data science libraries such as `pandas` and `numpy` are likely required.
3. Keep the dataset (`CIVE202_Spring2026_ENVRN-01-18_Project5_RRVWSP.csv`) in the same root directory as the notebook.
4. Open `CIVE202_Spring2026_ENVRN-01-18_Project5_PythonCode.ipynb` and run the cells sequentially.
